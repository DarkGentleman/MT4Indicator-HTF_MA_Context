# HTF_MA_Context 指标说明 v1.10

**一句话**：把 H1 的双均线多/空状态「投影」到 M15 主图上，作为看盘背景层——让你在读 M15 任何指标时，抬头就知道当前是否处在 H1 空头环境里。

- 源码：`HTF_MA_Context.mq4`（同目录）
- 类型：MT4 自定义指标，**不是 EA**；不产生买卖信号、不下单、不修改任何订单
- 建议图表：M15（参考周期默认 H1，1 根 H1 = 4 根 M15）
- 环境：MT4 build 600+ / MQL4 / `#property strict`

---

## 一、图表上会看到什么

| 元素    | 含义                            |
| ----- | ----------------------------- |
| 浅蓝背景块 | H1 快线 < 慢线，处于 **空头** 区间       |
| 浅粉背景块 | H1 快线 > 慢线，处于 **多头** 区间       |
| 两条竖线  | 状态翻转点（死叉起 / 金叉止），落在 H1 开盘整点   |
| 上方状态行 | 翻转备注：时间 + 当时两条均线值             |
| 下方状态行 | 区间统计：起止时间、持续 H1 根数、区间涨跌幅      |
| 右上角面板 | 默认只一行「当前 H1 双均线：空头」，颜色随状态变    |
| 虚线框   | 标出当前**尚未收盘**的 H1，方向待确认        |
| 深蓝线   | H1 慢线 SMA20 投影到 M15 价格坐标（默认开） |

背景置于 K 线**之下**（`OBJPROP_BACK`），不遮挡 M15 原有指标。上/下状态行采用多轨道错行 + 窄区间文字自动降级（完整 → 短版 → 单字「空/多」），连续窄多空交替也不会叠字。

## 二、安装

1. 把 `HTF_MA_Context.mq4` 复制到 `MT4数据目录/MQL4/Indicators/`。
2. MetaEditor 打开按 **F7** 编译。源码为 **UTF-8**；若 MT4 里中文乱码，改存为 **UTF-8 with BOM**。
3. 拖到 M15 图表，参数保持默认即可用。

## 四、关键机制：为什么不重绘

每根 M15 bar 的状态，由「它所属 H1 的**前一根已收盘 H1**」的均线决定，而不是当前未收盘的 H1。这样：

- 只用已收盘数据，无前视偏差；
- 对固定的 M15 bar，引用始终指向同一个绝对 H1 bar，**历史背景块一旦画上永不改写**；
- 代价：状态翻转最多滞后 1 根 H1（约 60 分钟），这是换取可信度的必要代价。

深蓝投影线与背景同源，同样取已收盘 H1 的 SMA20。

## 五、注意事项 / 待验证

- **本机没有 MetaEditor，源码未做真实编译**，请自行编译后先在模拟盘观察。
- 编译若报 `OBJPROP_FILL` 未定义（老 build）：删掉 `EnsureRect()` 里该行即可，矩形默认填充。
- 若报 `ChartTimePriceToXY` 或 `StringGetCharacter` 未定义，说明 MT4 build 过旧，需降级处理。
- 重点验证三件事：① H1 收盘前后背景块稳定、不回改；② 连续窄多/空区间完全不叠字；③ 深蓝线在 H1 边界连续、历史段不回改。
- 对象统一前缀 `HTFMAC_`，卸载指标时会自动清理；`InpMaxBars` 别设太大，以免对象过多卡顿。
